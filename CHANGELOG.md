# Changelog

All notable changes to AudiobookBuilder are documented here.

## 1.0.0 — 2026-08-19

- Build chaptered `.m4b` audiobooks from MP3, M4A, WAV, and FLAC files.
- Add batch modes for numbered files and one-book-per-subfolder collections.
- Embed title, author, genre, chapters, and optional cover artwork.
- Detect exact duplicate tracks and sort filenames naturally.
- Select Apple AudioToolbox AAC automatically when available.
- Add test coverage, macOS CI, packaging checks, and automated releases.
